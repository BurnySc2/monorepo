## Classes
```
htmx-indicator
```
Hides the element if a htmx request is pending.

```
loading-spinner
```
Spinner with this class will be shown if a request is pending. See below.

```
hx-indicator=".loading-spinner"
```
Shows all elements with class `loading-spinner`
